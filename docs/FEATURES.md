# NNIT Studio Feature Matrix

Recording: multitrack sessions, take lanes, punch workflow model, arming, monitoring integration point, metronome, device configuration.
Editing: timeline, trim/split/duplicate model, fades, clip gain, time positions, automation.
Production: MIDI/instrument track model, drum-rack and sampler integration boundaries, loop/content library boundary.
Mixing: channel strips, inserts, buses, sends, gain/pan, EQ, compressor, gate, de-esser, reverb, delay, saturation, stereo imaging.
Vocals: pitch engine integration point, de-essing, cleanup AI, harmony AI, doubling workflow.
Mastering: limiter, true peak, LUFS targets, stereo analysis model, mastering presets, AI master job.
AI: stem separation, denoise, isolation, BPM/key detection, transcription, harmony, mix and master assistance.
Collaboration: WebSocket project channel, cloud project/version model, approvals/comments boundary.
Business: plans, checkout boundary, marketplace data model, NNIT Pay boundary.
Global: locale/currency model, NNIT ID boundary, cloud storage boundary.
